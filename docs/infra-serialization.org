#+TITLE: Plan: Save/Load Serialization
#+OPTIONS: ^:{}

* Goal

Persist full game state to disk. Exit saves. Launch resumes the run where it left off
(like unpausing). Autosave every 30s during play. Native targets only, single save slot.

* Decisions (from design interview)

| Question          | Decision                                            |
|-------------------+-----------------------------------------------------|
| Scope             | Full Game state, resume-like-paused                 |
| Ordering          | Serialization before prestige; version field        |
| Slots             | Single slot                                         |
| Format            | Binary, structured, field-by-field                  |
| Web               | Native only; WASM backend deferred                  |
| Compatibility     | Version header; mismatch = reject load, start fresh |
| Save timing       | On exit + autosave every 30s                        |
| Exclusions        | Skip anything deterministically recomputable        |
| Location          | OS user data dir                                    |
| Integrity         | CRC32 checksum + atomic write (tmp + rename)        |
| Autosave interval | 30s                                                 |

* Save file format

Header, fixed size, all integers little-endian:

#+begin_example
magic    : [4]u8   "NBOD"                      (SAVE_MAGIC)
version  : u32     SAVE_VERSION (= 1)
length   : u64     payload byte count
crc32    : u64     checksum over payload bytes
#+end_example

Payload: field-by-field binary writes, explicit order, no padding, no raw struct dumps.

** Persisted fields (from Game)

- elapsed
- score (energy, energy_rate_ticker, total_objects, energy_gains, energy_losses ring buffers)
- timers (Score, Trail)
- help.launch_done
- camera.rl_cam.zoom, camera.rl_cam.target
- slingshot.available_objects, slingshot.output, slingshot.launch_power
- params (full Parameters struct: celestials, physics, slingshot)
- entities_count
- entities (full SOA array: sig, life, pos incl. trail, orbit incl. points, velocity, mass,
  radius, energy_source, emitter, celestial, renderable, collectible_energy, shockwave)
- free_entities_count, free_entities
- modifiers_count, modifiers

** Skipped fields (regenerated or recomputed on load)

- assets: GPU handles, reloaded by assets_init
- render: per-frame computed
- input: per-frame
- events: cleared every frame
- delete_entities, mass_delta: scratch buffers
- screenw, screenh, scale, dt: per-frame
- render.background (stars/nebulae): cosmetic, regenerated by background_init
- camera offset, shake: recomputed by sys_camera
- slingshot transient: status, preview/preview_points/preview_times/preview_count, snap,
  ring_flashes, start_pos/end_pos, obj_color/obj_radius, can_launch, shimmer_time
  -> reset to Inactive defaults on load

** Resume state

After load: status = .Paused (resume-like-paused). The user resumes manually
from the pause state; the game then continues from the saved elapsed time.

* Modules touched

** NEW game/persistence.odin
Not a sys_ file. Contains all serialize/deserialize/read/write procs.

Procs (names indicative):
- persist_serialize(g: ^Game, buf: []u8) -> (n: int, ok: bool)
  Writes header + payload into buf. Buffer-based so tests stay off disk.
- persist_deserialize(g: ^Game, buf: []u8) -> bool
  Validates magic, version, length, crc32. Populates persisted fields.
  Resets transient fields (slingshot Inactive, events cleared, camera offset recompute
  deferred to sys_camera). Returns false on any validation failure.
- persist_save_to_disk(g: ^Game) -> bool
  Serializes into static buffer, writes save.bin.tmp, renames to save.bin (atomic).
- persist_load_from_disk(g: ^Game) -> bool
  Reads save.bin if present, deserializes. Missing file = false, not an error.
- persist_save_dir :: proc() -> string
  OS user data dir. Linux: $XDG_DATA_HOME/nbody else ~/.local/share/nbody.
  macOS: ~/Library/Application Support/nbody. Windows: %APPDATA%\nbody.
  Creates dir if missing.
- persist_maybe_autosave(g: ^Game)
  Autosave tick. Called once per frame from game_run Playing branch;
  saves when SAVE_AUTOSAVE_INTERVAL_SEC elapsed since last save.

- SAVE_AUTOSAVE_INTERVAL_SEC :: 30
- SAVE_FILENAME :: "save.bin"
- MAX_SAVE_SIZE :: computed upper bound = header + entities array + free list + rest,

  fall through to existing game_reset(g). If true, skip game_reset and set status = .Paused,
  slingshot transient defaults.
- game_run: in .Playing branch, call persist_maybe_autosave(g).

Exit path: when loop ends (status == .Exit), call persist_save_to_disk(g) before game_free.

** NEW tests/persistence_test.odin
Tests (buffer API only, no disk):
- roundtrip: fixtures build populated Game -> serialize -> deserialize into zeroed Game
  -> assert all persisted fields equal (score, timers, camera zoom/target, slingshot fields,
  params, entities incl. trail/orbit arrays, free list, modifiers, help, elapsed)
- wrong magic -> deserialize returns false
- wrong version -> deserialize returns false
- corrupted payload byte -> crc mismatch -> returns false
- truncated buffer -> returns false
- autosave tick fires only after SAVE_AUTOSAVE_INTERVAL_SEC

* Runtime flow

Startup:
1. game_init runs: window, assets, params, theme, input, background.
2. persist_load_from_disk:
   - no file / invalid -> game_reset (current fresh-start path, unchanged)
   - valid -> populate fields, status = .Paused (user resumes manually),
     slingshot reset to Inactive, events_count = 0

During play: persist_maybe_autosave in Playing branch; saves at most once per 30s.

Exit: main loop ends -> persist_save_to_disk -> game_free.

* Failure handling

- Corrupt/incompatible save: reject, start fresh, never crash.
- Save write failure: fail silently (no inline logging allowed; dedicated log
  file deferred to docs/plan.org Infrastructure track), game continues.
- Save dir creation failure: fail silently, saving disabled for session.

* Deferred (also filed in docs/plan.org)

- WASM persistence backend (IndexedDB/localStorage via emscripten)
- Prestige fields in save format (bump SAVE_VERSION when prestige lands)
- Migration system for old saves (post-release only)
- Pause-menu manual save button

* Acceptance criteria

- make test green, including new persistence tests
- Run game, spawn objects, quit, relaunch: state resumes (energy, entities, camera zoom)
- Kill -9 the game, relaunch: resumes from last autosave (<= 30s loss)
- Corrupt save.bin manually: game starts fresh, no crash
- No heap allocations added; static buffer only
